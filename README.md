# CodeMentorAI 💻🤖

AI-powered coding assistant designed to help users write, understand, debug, and execute code.

## 🚀 Features

- 🤖 AI-powered code analysis
- 🐛 Error and bug analysis
- 💡 Code explanations and suggestions
- ▶️ Code execution
- 📊 Execution history
- ⚙️ User settings
- 🔐 User authentication
- 📝 Interactive code workspace

## 🛠️ Tech Stack

### Frontend
- React
- TypeScript
- Vite
- Tailwind CSS

### Backend
- Node.js
- Express
- TypeScript

### AI
- Google Gemini API

### Database
- MongoDB

### Editor
- Monaco Editor

## 🏗️ Architecture

The application consists of:

1. React frontend
2. Interactive code editor
3. Express backend
4. Gemini API integration
5. MongoDB database
6. Code execution service
